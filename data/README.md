### 📋 Description

| Property | Value |
|----------|-------|
| Records | 15,420 claims |
| Features | 33 attributes (32 predictors + 1 target) |
| Target | `FraudFound_P` (1 = fraud, 0 = legitimate) |
| Class balance | 923 fraud (~6%) vs. 14,497 legitimate — severe imbalance |
| Period | January 1994 – December 1996 |
| Feature types | Predominantly categorical (24 of 33), low-cardinality; no claim-amount field |

Captures demographic, policy, and behavioral attributes — e.g. `Fault`, `PastNumberOfClaims`, `PoliceReportFiled`, `WitnessPresent`, `AddressChange_Claim`, `Days_Policy_Accident`.

### 📝 Notes

- Fraud labels are historical, adjuster-confirmed outcomes and are treated as ground truth.
- Known data-quality issues (handled in preprocessing): `PolicyNumber` is dropped as a row identifier; invalid `Age` zero-entries and placeholder claim-date fields are treated as missing.
- Cleaned data and train/validation/test splits are generated by `notebooks/02_preprocessing_and_splitting.ipynb` and saved to Drive; they are **not** committed to this repo.
